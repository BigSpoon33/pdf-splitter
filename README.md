# monograph-splitter web

A public website on top of [monograph-splitter](https://git.gumshu.duckdns.org/shuma/monograph-splitter): drag in a large text-layer PDF, choose how sections are found (PDF outline, big headings, or a pasted list), tune the layout (columns, bands), preview and drag the cuts, and download one PDF per chapter/entry.
